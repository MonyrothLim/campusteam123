Campus Teams
Campus game registration

Get registered. Get on the team.

A simple way to manage sign-ups, control capacity, and split registered students into balanced-size teams.

Setup required: add your Supabase project URL and public anon key in the CONFIG section of index.html, then run schema.sql in Supabase SQL Editor. See README.md.
